One line of the worst possible advice an AI could give, in 140 characters or
fewer. A house judge model compares the lines two at a time on funniness,
tightness, AI voice, and how concrete the bad advice is.

> If your code won't compile, rename the errors to warnings and ship it anyway.

## Run it

```sh
python3 main.py
```

`main.py` writes the line to `/output/entry.txt` (77 characters, one line,
one sentence, verified by assertions in the program itself). Deterministic,
no network, no randomness.
